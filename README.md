# To-Do List App

## Project Overview

This To-Do List App is a simple web application built using HTML, CSS, and JavaScript. The purpose of this project is to help users stay organized by keeping track of their daily tasks.

I created this project as part of my programming capstone to practice my web development skills and better understand how JavaScript works with HTML and CSS.

## Features

- Add new tasks to a to-do list.
- Display tasks on the page.
- Mark tasks as completed.
- Delete tasks that are no longer needed.
- Simple and user-friendly design.

## Technologies Used

- **HTML5:** Creates the structure of the application.
- **CSS3:** Styles the page and makes it visually appealing.
- **JavaScript:** Adds functionality and allows users to interact with the to-do list.

## How to Use

1. Open the application in a web browser.
2. Type a task into the input field.
3. Click the Add Task button to add it to the list.
4. Mark a task as completed when finished.
5. Delete tasks you no longer need.

## Project Goals

The main goal of this project was to practice using JavaScript to create an interactive website without using frameworks like React.

While building this project, I focused on:

- Working with the Document Object Model (DOM).
- Using JavaScript functions and event listeners.
- Handling user input.
- Updating HTML elements dynamically.
- Improving my problem-solving and debugging skills.

## Future Improvements

Some features I would like to add in the future include:

- Saving tasks using localStorage so they remain after refreshing the page.
- Adding due dates for tasks.
- Organizing tasks by priority.
- Filtering tasks by completed and incomplete status.
